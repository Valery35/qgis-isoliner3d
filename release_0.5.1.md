# Публикация Isoliner3D 0.5.1

Три архива, три шага. Порядок важен: сначала репозиторий, потом каталог.
Если каталог отклонит сборку, в репозитории уже будет то, на что можно
сослаться в переписке.

## Что в архивах

| Архив | Куда | Что внутри |
|---|---|---|
| `isoliner3d.zip` | GitHub, релиз | папка модуля целиком, с `tests/` и PDF |
| `isoliner3d_upload.zip` | plugins.qgis.org | то же без `isoliner3d/tests/` |
| `isoliner3d_repo_delta.zip` | GitHub, файлы репозитория | AGENTS.md, README.md, `manual/` |

Внутри модуля лежат `doc/Isoliner3D.pdf` и `doc/Isoliner3D_en.pdf`, они
нужны кнопке Справка. Исходник руководства в плагин не попадает.

## Шаг 1. Репозиторий

1. Распакуйте `isoliner3d_repo_delta.zip` в корень локальной копии
   `qgis-isoliner3d`, поверх существующих файлов.
2. Распакуйте `isoliner3d.zip` туда же: он положит папку `isoliner3d`
   поверх старой. Перед распаковкой удалите старую папку `isoliner3d`
   целиком, иначе в ней останутся файлы, которых больше нет в сборке
   (например, прежний `demo_map`-инструмент отдельным классом уже не
   существует, но файлов после него не остаётся, так что это скорее
   привычка на будущее).
3. В GitHub Desktop проверьте список изменений. Ожидается: правка
   `metadata.txt`, `viewer3d.py`, `algorithms.py`, `i18n.py`, `texmesh.py`,
   README.md, AGENTS.md, оба файла руководства и оба PDF.
4. Commit с текстом `Isoliner3D 0.5.1`, затем Push.

## Шаг 2. Релиз на GitHub

1. На странице репозитория: Releases, Draft a new release.
2. Tag: `v0.5.1`, создать новый на ветке `main`.
3. Заголовок: `Isoliner3D 0.5.1`.
4. Описание: возьмите блок `changelog` из `metadata.txt`, он уже написан
   как список выпуска.
5. Прикрепите файлом `isoliner3d.zip` (рабочий, с тестами).
6. Publish release.

## Шаг 3. Каталог plugins.qgis.org

1. Войдите под своим OSGeo ID.
2. Так как плагина в каталоге ещё нет, это первая загрузка:
   `https://plugins.qgis.org/plugins/add/`.
3. Файл: `isoliner3d_upload.zip`. Именно он, без `tests/`.
4. После загрузки проверьте на странице плагина: версия 0.5.1,
   Experimental снят, автор и ссылки на месте.
5. Первая публикация проходит ручную модерацию. Ответ приходит письмом,
   обычно в течение суток или двух.

Если сканер отклонит сборку, пришлите текст отказа. По моей проверке
претензий быть не должно: bandit по своему коду даёт ноль замечаний
на всех уровнях, по вложенным библиотекам тоже ноль, запрещённых
конструкций `except: pass` и `except: continue` в своём коде нет.

## Проверка после установки

Поставьте `isoliner3d_upload.zip` через Модули - Установить из ZIP
и убедитесь по списку:

- в меню Модули появился раздел **Isoliner3D** с двумя пунктами,
  3D-просмотр и Справка;
- Справка открывает PDF на языке интерфейса;
- в панели Обработка есть провайдер **Isoliner3D**, группа
  **Пласт и блочная модель**, семь инструментов с номерами 1.01 - 1.07;
- окно 3D открывается, сцена собирается, в строке состояния видны
  счётчики;
- повторное **Обновить сцену** укладывается в сотые доли секунды
  и показывает **взято из кэша**;
- текстура ложится, чертёж разреза встаёт на ленту.

Перезапуск QGIS не нужен.

## Что осталось незакрытым

Это не мешает выпуску, но стоит помнить.

- Скриншота для README нет, в файле стоит закомментированная ссылка
  на `docs/screenshot.png`. Кадр из окна с текстурой и разрезом закрыл бы
  вопрос.
- Раздела модуля на сайте нет.
- Главы руководства про группу инструментов идут без иллюстраций.
- Рендер текстур на реальном железе проверен только вами и только на одной
  машине. Драйверы разные, и первый отчёт о чёрной поверхности вполне
  возможен.
