## Русский (ВК, Facebook)

Isoliner3D 1.5.2 для QGIS

Все параметры вида сцены собраны в одно окно «Параметры сцены» за одной кнопкой. Четыре вкладки: вид с камерой (азимут, наклон, удаление, угол обзора, проекция), оформление, координатный короб и обрезка. Окно стало компактным, на плашке остались только действия.

То же окно с тем же набором полей теперь в программе Isoliner Scene: список общий, и сцена настраивается одинаково в QGIS и без него.

## English (LinkedIn, Mastodon)

Isoliner3D 1.5.2 for QGIS

All scene view settings now live in one Scene settings window behind a single button. Four tabs: view with the camera (azimuth, elevation, distance, field of view, projection), appearance, coordinate box and clipping. The window is compact, and the toolbar keeps only actions.

Isoliner Scene gets the same window with the same fields from a shared list, so a scene is set up the same way inside QGIS and without it.

Plugin: https://github.com/Valery35/qgis-isoliner3d/releases/tag/1.5.2
